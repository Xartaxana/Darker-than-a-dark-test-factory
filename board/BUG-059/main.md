# BUG-059 — Счётчик снекбара показывает общее число вкладок, а не число открытых в фоне

## Окружение
- Версия приложения: 1.11 (versionCode 12)
- Режим: replay (`listing_basic.mitm`)
- Тема: не указана (по умолчанию)

## Шаги воспроизведения (Given-When-Then)

**Given**
Приложение запущено, текущая вкладка — Home (одна вкладка открыта).

**When**
Открыть вкладку Library → long-press по карточке → выбрать «Open in background tab».

**Then (ожидалось)**
Снекбар показывает «Opened in background (1 tab)» — число открытых в фоне.

**Actual (фактически)**
Снекбар показывает «Opened in background (2 tabs)» — общее число открытых вкладок (Home + только что открытая).

## Частота
Всегда (>20 наблюдений во всех прогонах CH-009 сессии 2026-08-10).

## Артефакты
- Протокол exploratory-charters/CH-009.md (found_bugs #0, строка 13)
- Скриншоты в exploratory-charters/attachments/CH-009/ (все пять прогонов CH-009)

## Анализ
Код в `BrowserViewModel.kt:283` передаёт `BackgroundTabOpen(..., newTabs.size)`, где `newTabs.size` — ОБЩЕЕ число вкладок (включая Home, которая всегда открыта; см. `:335-337` авто-открытие Home при закрытии последней).

Счётчик правильно отображается в снекбаре (`MainActivity.kt:276`), но число в сигнале — неправильное по семантике: код содержит комментарий о «замене» последовательных сообщений, но сам счётчик отражает длину списка вкладок, а не длину открытых В ФОНЕ.

**Важно:** та же проблема воспроизводится и во ВТОРОЙ фоновой двери (`BrowserScreen.kt:647`, long-press по ссылке внутри WebView, TC-026). Фикс обязан закрывать обе двери.
