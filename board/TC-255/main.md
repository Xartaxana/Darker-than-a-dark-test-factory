# TC-255 — Граница перехвата: вне Browse клавиши свободны

## Предусловия
- Настройка «Page with volume buttons» ON (включена — граница проверяется
  ИМЕННО при включённой настройке, иначе неотличимо от TC-253). Пользователь
  на вкладке Library.

## Сценарий (Given-When-Then)

**Given** настройка ON, выбранная нижняя вкладка — Library (не Browse)

**When** пользователь нажимает VOLUME_DOWN

**Then** системный индикатор громкости появляется, реальная громкость
устройства меняется штатно — приложение НЕ перехватывает клавишу, пока
активна вкладка, отличная от Browse, невзирая на включённую настройку

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Настройка | ON |
| Выбранная вкладка | Library (вариация прогона — Settings) |
| Ожидаемый эффект | штатное системное изменение громкости |

## Заметки для автоматизации
