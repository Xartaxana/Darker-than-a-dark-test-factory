# TC-241 — Оценка работы из Library без открытия AO3-страницы

## Предусловия
- Работа W засеяна как placeholder БЕЗ рейтинга (полные title/author/
  fandom/wordCount, тот же приём, что TC-007/TC-112), видна на вкладке
  Library (например, во вкладке «All» или ином не-рейтинговом представлении
  — конкретика зависит от факт. UI, сверяется при кодировании).

## Сценарий (Given-When-Then)

**Given** работа W без рейтинга видна на экране Library, overlay длинного
нажатия открыт, выбран пункт «Rate / edit note»

**When** пользователь ставит рейтинг READ, вводит заметку и один личный тег,
сохраняет

**Then** рейтинг/заметка/тег сохранены (подтверждено чтением Room —
`read_work_ratings_full()`)
**And** карточка W переезжает во вкладку READ экрана Library
**And** экран остаётся Library на всём протяжении сценария — НИ ОДНА
вкладка браузера не создана, AO3-страница работы не открывалась

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Работа W | placeholder-сидинг без рейтинга |
| Рейтинг | READ (не Kudos/Favorite — та ветка отдельным кейсом TC-242/243) |
| Заметка/тег | произвольные непустые |

## Заметки для автоматизации
- Новый UI-элемент (overlay-пункт «Rate / edit note» → `RatingOverlay`
  внутри Library) — потребует нового screen-объекта/шагов
  (`library_screen.py` расширение), это обычная работа test-automator, не
  test_debt.
- Рейтинг READ выбран намеренно НЕ-kudos-ным — переходы в Kudos/Favorite
  несут отдельные побочные эффекты, покрытые TC-242..245.
