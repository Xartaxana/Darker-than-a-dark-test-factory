# Off-инвариант: авто-триггер молчит без единого сетевого вызова, пока токен пуст

# TC-227 — Батарея: off-инвариант авто-триггера (пустой токен)

## Предусловия
- Приложение запущено с чистыми данными, токен синхронизации ПУСТ
  (синхронизация не настроена вовсе). Устройство под mitm-прокси, весь
  трафик наблюдаем.

## Сценарий (Given-When-Then)

**Given** токен синхронизации пуст

**When** пользователь оценивает работу (локальное изменение БД) и затем
сворачивает/разворачивает приложение (передний план — второй триггер)

**Then** за всё время сценария к хосту синхронизации НЕ уходит НИ ОДНОГО
сетевого запроса (mitm-перехват показывает 0 запросов к
`sync_gitlab_url`/`/api/v4/snippets`) — ни на изменение БД, ни на выход на
передний план
**And** подпись «Last synced …» в Settings остаётся «Not synced yet»

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Токен | пусто |
| Действия | 1 оценка работы + 1 цикл фон/передний план |
| Ожидаемое число сетевых запросов к sync-хосту | 0 |

## Заметки для автоматизации
- **Наблюдаемость негативного Then (обязательная оговорка):** проверка
  ведётся ЧЕРЕЗ mitm-перехват фактических запросов к хосту синхронизации
  (или отсутствие таковых), а НЕ через отсутствие UI-диалога — если бы
  гипотетический баг всё же ушёл в сеть при пустом токене, тест обязан это
  увидеть по трафику, а не по молчанию экрана.
- Требует поднятого mitm-прокси в режиме наблюдения (не обязательно
  replay/mock-ответа — сам факт ЛЮБОГО запроса к хосту уже провал) — доступно
  тем же механизмом, что replay-фикстура (`framework/core/mitm.py`).
