# BUG-050 — Длинный заголовок в снекбаре Undo обрезается без многоточия

## Окружение
- Версия: 1.10 (versionCode 11), commit 63f6aac

## Шаги воспроизведения (Given-When-Then)

**Given** вкладка с работой, заголовок длиннее ~40 символов
**When** вкладка закрывается свайпом — снекбар показывает заголовок
**Then (ожидание)** обрезка с многоточием (ellipsis)
**Then (факт)** текст обрывается на границе, без «…» — выглядит как битая строка

## Частота
Всегда при длинном заголовке.

## Анализ
Косметика TextOverflow в снекбаре; данных не теряет.
