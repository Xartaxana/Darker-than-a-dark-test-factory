# TC-247 — Плавающие кнопки листания: направление и шаг

## Предусловия
- E-ink mode ON, «Show page-turn buttons» ON, работа открыта в Browse
  (длинная страница, есть куда листать в обе стороны — прокручено на
  середину).

## Сценарий (Given-When-Then)

**Given** обе настройки ON, активная вкладка открыта на середине длинной
страницы, зафиксирована исходная scroll-позиция S0

**When** пользователь дважды тапает правую кнопку (BottomEnd), затем дважды
левую

**Then** после первого тапа правой кнопки scroll-позиция сдвинулась ВПЕРЁД
примерно на 0.9 высоты экрана (S0 → S1 ≈ S0 + 0.9·H); второй тап — ещё на
столько же (S1 → S2 ≈ S1 + 0.9·H, линейно, без удвоения/пропуска)
**And** после первого тапа левой кнопки позиция сдвинулась НАЗАД примерно на
0.9·H (S2 → S3 ≈ S2 − 0.9·H); второй — ещё на столько же

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Обе настройки | ON |
| Шаг за тап | ≈0.9 × высота экрана |
| Направление | правая = вперёд, левая = назад |

## Заметки для автоматизации
- Блокера нет — тап по видимым Compose-кнопкам, измерение scroll-позиции
  тем же приёмом, что уже используется для WebView-скролла в существующих
  browser-кейсах.
