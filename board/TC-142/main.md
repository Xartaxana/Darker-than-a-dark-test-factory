# TC-142 — Переход Kudosed → Read через листинг не кликает kudos

## Предусловия
- Приложение запущено, режим replay (`listing_basic.mitm`, после фикса
  `bugs/AT-BUG-035.md`).
- Работа W = `LOVED` (900000001) засеяна напрямую в Room с рейтингом LIKE
  (Kudosed), без личных тегов.
- Открыты ДВЕ вкладки: Tab A — листинг с блёрбом W (бейдж Kudosed); Tab B —
  work-страница W, открытая в фон (тот же приём, что TC-138/139) — открытая
  вкладка нужна, чтобы условие `:857-858` МОГЛО сработать, если бы гипотетический
  баг ошибочно кликал и при смене рейтинга — кейс доказывает, что несмотря на
  присутствие такой вкладки, клика нет.
- На Tab B узел `#kudo_submit` без `data-kudo-clicked` (baseline).

## Сценарий (Given-When-Then)

**Given** работа W имеет рейтинг Kudosed (LIKE); открыты Tab A (листинг, бейдж
Kudosed) и Tab B (work-страница W, `#kudo_submit` без `data-kudo-clicked`)

**When** на Tab A пользователь Rate-кнопкой W открывает bottom-sheet и выбирает
рейтинг «Read» (смена рейтинга, НЕ правка метаданных — реальный переход на
значение вне множества {LIKE, SAVE})

**Then** рейтинг меняется на Read — работа W перемещается из вкладки Kudosed во
вкладку Read экрана Library
**And** ПОСЛЕ этого Tab A закрывается (`browser_steps.swipe_close_tab(driver,
position=0)`) — идиома reduce-to-one (тот же приём, что TC-138/139, обоснование
`browser_screen.py:319-329`, см. заметки): Tab B остаётся единственной живой
WebView, chromedriver переподключается к ней. На Tab B узел `#kudo_submit` НЕ
получает `data-kudo-clicked` — новое сохраняемое значение (`READ`) не входит в
предикат `:856`, evalJs с kudos-кликом структурно не строится для этого вызова

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Работа W | `W.LOVED`, засеяна напрямую с rating=LIKE → READ |
| Открытые вкладки | Tab A (листинг), Tab B (work-страница W) |

- **Батарея правил-реакций** (место вызова `:856`, листинговый путь, тот же, что

  - идемпотентность — **н-п**: единичное действие, повтор не предмет этого кейса.
  - propagation — **н-п**, см. TC-138 (единственный потенциальный потребитель —
    Tab B, и тот не получает эффекта).
