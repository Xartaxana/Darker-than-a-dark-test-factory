# TC-211 — Переоценка снимает надгробие (undelete)

## Предусловия
- Синхронизация настроена. Для работы Z в таблице `sync_tombstones` заранее
  проставлено надгробие (`kind="work"`, `deletedAt=T_delete`) — прямой сидинг
  в Room, минуя UI (симулирует «работа была удалена ранее»).
- Удалённый снимок (мок) несёт СТАРУЮ строку Z с `timestamp=T_row <
  T_delete` (та же форма контроля, что TC-210: без переоценки надгробие не
  дало бы строке воскреснуть).

## Сценарий (Given-When-Then)

**Given** работа Z несёт надгробие `deletedAt=T_delete`, удалённый снимок
несёт более старую строку Z

**When** пользователь заново оценивает работу Z (любой рейтинг, из листинга
или с панели работы)

**Then** надгробие Z снято — последующий запуск «Sync now» с ТЕМ ЖЕ старым
удалённым снимком Z НЕ удаляет работу повторно (в отличие от TC-210, где без
переоценки Z осталась бы отсутствующей, здесь Z присутствует и после синка)
**And** надгробие Z ФИЗИЧЕСКИ снято — различающий оракул (без него Then
выполняется и при сломанном снятии): в теле опубликованного JSON массив
`tombstones` НЕ содержит записи `{"kind":"work","id":Z}` (перехват
исходящего тела, приём TC-215/TC-234) ЛИБО прямое чтение таблицы
`sync_tombstones` на устройстве не даёт строки для Z

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Работа Z | надгробие deletedAt=T_delete (прямой сидинг) |
| Удалённая строка | timestamp=T_row < T_delete |
| Действие | переоценка Z ДО запуска sync |

## Заметки для автоматизации
- Прямой сидинг `sync_tombstones` — сидера/хелпера для этой таблицы в
  `framework/data/seed_db.py` НЕТ (есть только `work_ratings`/
  `filter_profiles`). Информация для test-automator (не блокер этому
  дизайну): понадобится аналог `_insert_rows_filter_profiles` для
  `sync_tombstones` (схема — `kind TEXT, id TEXT, deletedAt INTEGER`,
  составной PK).
- Sync-фикстура (мок снимка) отсутствует — тот же класс, что TC-207..210.
- Кейс НЕ зависит от TC-210 по порядку (правило независимости): состояние
  «есть надгробие» создаётся прямым сидингом, не проходом сценария TC-210.
