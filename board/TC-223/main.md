# TC-223 — Первое устройство: авто-создание приватного сниппета

## Предусловия
- Синхронизация настроена (instance + токен заполнены), поле Snippet ID
  ПУСТО — типичное первое устройство.

## Сценарий (Given-When-Then)

**Given** Snippet ID пуст, instance/токен заполнены валидными значениями

**When** пользователь нажимает «Sync now»

**Then** приложение создаёт приватный GitLab-сниппет (title «AO3 Reader
library sync», файл `ao3_library_sync.json`, `visibility: private` — виден в
теле запроса на создание)
**And** диалог называет номер созданного сниппета (текст отличается от
диалогов TC-221/222/TC-216 — несёт конкретный ID)
**And** поле Snippet ID в Settings САМО заполняется этим номером (без
действий пользователя)

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Snippet ID до прогона | пусто |
| Ожидаемое тело запроса создания | title=«AO3 Reader library sync», file_name=`ao3_library_sync.json`, visibility=`private` |
| Snippet ID после прогона | номер, названный диалогом, совпадает со значением поля |

## Заметки для автоматизации
- Sync-фикстура отсутствует — требует мока СОЗДАНИЯ сниппета (POST,
  возвращающего произвольный id) — тот же класс инфраструктурного долга,
  что предыдущие кейсы области, информация для test-automator.
