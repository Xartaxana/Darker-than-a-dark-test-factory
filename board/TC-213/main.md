# TC-213 — Надгробие удаляет фильтр-профиль на всех устройствах

## Предусловия
- Синхронизация настроена. Локально сохранён фильтр-профиль Q.
- Удалённый снимок (мок) несёт НАДГРОБИЕ `kind="profile"` для `id` профиля Q
  с `deletedAt` позже локального `timestamp` профиля.

## Сценарий (Given-When-Then)

**Given** локальный профиль Q и более свежее входящее надгробие того же `id`

**When** пользователь запускает «Sync now»

**Then** профиль Q исчезает из списка Settings
**And** профиль Q исчезает из селектора панели фильтров листинга (Browse)

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Профиль Q | сохранён локально |
| Удалённое надгробие | kind=profile, deletedAt позже timestamp профиля |

## Заметки для автоматизации
- Sync-фикстура отсутствует — тот же класс, что предыдущие кейсы области;
  тот же нюанс с `id` профиля, что TC-212.
