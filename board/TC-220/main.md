# TC-220 — Гейт кнопки «Sync now» по наличию токена

## Предусловия
- Секция Sync открыта, поле токена пусто (остальные поля могут быть
  заполнены произвольно).

## Сценарий (Given-When-Then)

**Given** токен пуст

**When** пользователь смотрит на кнопку «Sync», затем вводит непустой токен

**Then** пока токен пуст — кнопка «Sync» неактивна (не нажимается, ни один
сетевой запрос не уходит)
**And** после ввода непустого токена кнопка становится активной

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Токен | пусто → произвольная непустая строка |
| Ожидаемое состояние кнопки | disabled → enabled |

## Заметки для автоматизации
- Блокера нет — проверка `enabled`-атрибута Compose-кнопки, стандартный
  приём.
