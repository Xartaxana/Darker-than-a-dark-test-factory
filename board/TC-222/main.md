# TC-222 — Ручной прогон без входящих изменений

## Предусловия
- Синхронизация настроена. Локально есть 1 неопубликованное изменение,
  удалённый снимок (мок) СОВПАДАЕТ с предыдущим успешным синком (никаких
  входящих изменений).

## Сценарий (Given-When-Then)

**Given** есть только локальное неопубликованное изменение, входящих
изменений нет

**When** пользователь нажимает «Sync now»

**Then** диалог показывает дословно «No incoming changes. Snippet updated.»
**And** удалённый сниппет получает запись (перехват mitm видит записывающий
запрос — в отличие от TC-216, где записи не было вовсе)

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Локально | 1 неопубликованное изменение |
| Удалённо | без изменений относительно прошлого синка |
| Диалог | «No incoming changes. Snippet updated.» |

## Заметки для автоматизации
- Sync-фикстура отсутствует — тот же класс, что предыдущие кейсы области.
- Отличать от TC-216 («Everything already in sync.» — нет ни локальных, ни
  входящих изменений, запись не происходит вовсе) — здесь ЕСТЬ запись,
  просто без входящих изменений.
