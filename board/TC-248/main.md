# TC-248 — AND-предикат видимости плавающих кнопок

## Предусловия
- Работа открыта в Browse. Проверяются три ложные комбинации настроек: (а)
  E-ink OFF, page-turn-buttons OFF; (б) E-ink ON, page-turn-buttons OFF; (в)
  E-ink OFF, page-turn-buttons ON (значение сохранено из прошлого ON-состояния,
  но сам E-ink сейчас выключен).

## Сценарий (Given-When-Then)

**Given** работа открыта в Browse

**When** настройки последовательно приводятся к каждой из трёх ложных
комбинаций (а)/(б)/(в) выше

**Then** ни в одной из трёх комбинаций плавающие кнопки листания НЕ видны
на экране Browse

Инвариант: кнопки видимы ТОЛЬКО при истинности ОБОИХ условий одновременно
(`einkMode && showPageTurnButtons`); отсутствие любого ОДНОГО из двух —
кнопок нет, независимо от состояния другого.

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Комбинация (а) | eink=OFF, buttons=OFF → нет кнопок |
| Комбинация (б) | eink=ON, buttons=OFF → нет кнопок |
| Комбинация (в) | eink=OFF, buttons=ON (сохранённое значение) → нет кнопок |
| (Четвёртая, true×true) | покрыта отдельным кейсом TC-247 |

## Заметки для автоматизации
- При кодировании естественно параметризовать ОДНИМ тестом по трём
  комбинациям (`pytest.mark.parametrize`) — дизайн описывает их одним
  сценарием намеренно (общее свойство), автоматизация вправе выбрать
  реализацию.
- Блокера нет.
