# TC-225 — Ошибка 401/403: токен без нужного scope

## Предусловия
- Синхронизация настроена, Snippet ID валиден, но мок GitLab отвечает
  `401` (или `403`) на запрос — симулирует токен без scope `api`. Локально
  есть оценённая работа.

## Сценарий (Given-When-Then)

**Given** мок отвечает 401/403 на запрос к сниппету, локально есть
оценённая работа X

**When** пользователь нажимает «Sync now»

**Then** показан диалог «Sync failed» с дословным текстом «GitLab rejected
the token (HTTP <code>). It needs the 'api' scope.», где `<code>` — реально
полученный код (401 или 403)
**And** локальные данные работы X НЕ изменились

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Ответ мока | 401 (вариант прогона — 403) |
| Диалог | «GitLab rejected the token (HTTP 401). It needs the 'api' scope.» |

## Заметки для автоматизации
- Sync-фикстура отсутствует — тот же класс, что TC-224. Автоматизации
  достаточно ОДНОГО из двух кодов (401 ИЛИ 403) как представителя ветки —
  код обрабатывает их идентично (`SyncRepository.kt:250-256` не различает
  401/403 в тексте сообщения, только подставляет фактический код).
