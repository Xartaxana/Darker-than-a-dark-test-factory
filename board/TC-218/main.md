# TC-218 — Поля конфигурации Sync: маска токена и персистентность

## Предусловия
- Приложение запущено с чистыми данными, секция Sync в Settings открыта,
  все три поля (GitLab instance, access token, snippet ID) пусты.

## Сценарий (Given-When-Then)

**Given** секция Sync открыта, поля пусты

**When** пользователь вводит значение в каждое из трёх полей (instance,
токен, snippet ID), проверяет, что токен отображается замаскированным,
нажимает Show и видит его в открытом виде, нажимает Hide и видит маску
снова, затем перезапускает приложение (kill+relaunch) и вновь открывает
Settings

**Then** токен по умолчанию замаскирован (до нажатия Show)
**And** Show раскрывает токен в открытом виде, Hide маскирует обратно
**And** после перезапуска все три поля показывают ранее введённые значения
без потери данных

## Проверяемые данные
| Параметр | Значение |
|---|---|
| GitLab instance | произвольный валидный URL, например `https://gitlab.example.test` |
| Access token | произвольная непустая строка |
| Snippet ID | произвольное число, например `12345` |

## Заметки для автоматизации
- Блокера нет — обычный settings-persistence паттерн (kill+relaunch), уже
  используется другими settings-кейсами области (например TC-047..049).
