# TC-252 — Основной путь: листание Browse кнопками громкости

## Предусловия
- Настройка «Page with volume buttons» ON, пользователь на вкладке Browse
  с длинной прокручиваемой страницей.

## Сценарий (Given-When-Then)

**Given** настройка ON, активная вкладка Browse открыта на середине длинной
страницы (позиция S0)

**When** пользователь дважды нажимает VOLUME_DOWN, затем дважды VOLUME_UP

**Then** каждое нажатие VOLUME_DOWN сдвигает scroll-позицию активной
вкладки ВПЕРЁД примерно на экран (линейно за каждое нажатие, без
накопления/пропуска)
**And** каждое нажатие VOLUME_UP сдвигает позицию НАЗАД примерно на экран
**And** ни на одно из четырёх нажатий системный индикатор громкости НЕ
появляется на экране (перехват key-up тоже работает — не остаётся
«зависшего» системного UI)

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Настройка | ON |
| VOLUME_DOWN | вперёд ~1 экран за нажатие |
| VOLUME_UP | назад ~1 экран за нажатие |
| Системный индикатор громкости | не появляется ни разу |
