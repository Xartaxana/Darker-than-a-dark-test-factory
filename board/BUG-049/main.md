# BUG-049 — Снекбар «Tab closed» перекрывает нижнюю навигацию на узких экранах

## Окружение
- Версия: 1.10 (versionCode 11), commit 63f6aac
- Узкий экран (ширина < 360dp, крупный шрифт системы)

## Шаги воспроизведения (Given-When-Then)

**Given** открыт браузер с ≥2 вкладками, системный шрифт увеличен
**When** пользователь закрывает вкладку свайпом — появляется снекбар «Tab closed» с Undo
**Then (ожидание)** снекбар не перекрывает нижнюю навигацию
**Then (факт)** на узких экранах снекбар ложится поверх таба Library — пока он видим, переключиться нельзя

## Частота
Стабильно на узкой конфигурации.

## Анализ
Косметика позиционирования снекбара; функциональной потери нет (снекбар
уходит по таймауту). Разработчик пометил Fixed в своей ветке.
