# TC-245 — Broadcast бейджа на открытую вкладку листинга

## Предусловия
- Вкладка браузера с листингом (replay), содержащим блёрб работы W, уже
  открыта и видна пользователю (переключение на неё после Library не
  требуется). W засеяна без рейтинга.

## Сценарий (Given-When-Then)

**Given** вкладка листинга с блёрбом W уже открыта в фоне, W без рейтинга

**When** пользователь на экране Library оценивает W как Favorite через
«Rate / edit note»

**Then** переключившись на фоновую вкладку листинга (БЕЗ навигации/reload
страницы), пользователь видит бейдж W уже обновлённым до Favorite — то же
свойство broadcast, что уже проверено для остальных путей оценки
(`applyRatings` синхронизирует все открытые вхождения)

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Работа W | без рейтинга → Favorite |
| Открытая вкладка | листинг (replay) с блёрбом W, в фоне |

## Заметки для автоматизации
- Переиспользует существующий приём/фикстуру `listing_basic.mitm` и
  `applyRatings`-оракул, уже использованные TC-012 (та же семантика
  broadcast, но с ДРУГОГО входа — из Library, а не из листинга самого по
  себе) — блокера не ожидается сверх обычной проводки нового
  screen-объекта overlay.
