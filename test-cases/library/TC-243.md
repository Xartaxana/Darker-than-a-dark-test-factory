# TC-243 — Kudos из Library НЕ отправляется без открытой вкладки работы

## Предусловия
- Работа W засеяна без рейтинга. НИ ОДНА вкладка браузера не открыта (или
  открыты вкладки ДРУГИХ работ, но не W). Устройство под mitm-прокси
  (наблюдение сети).

## Сценарий (Given-When-Then)

**Given** работа W без рейтинга, ни одна открытая вкладка не содержит её
AO3-страницу

**When** пользователь на экране Library оценивает W как «Kudosed» через
«Rate / edit note»

**Then** рейтинг W сохраняется как LIKE (сохранение рейтинга произошло —
подтверждает, что When реально случился)
**And** к AO3 НЕ уходит НИ ОДНОГО kudos-запроса (mitm-перехват показывает 0
POST на `kudo`-эндпоинт за весь сценарий) — контраст с TC-242

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Работа W | без рейтинга → LIKE (Kudosed) |
| Открытые вкладки | без work-страницы W (пусто или другие работы) |
| Ожидаемое число kudos-запросов | 0 |

## Заметки для автоматизации
- **Наблюдаемость негативного Then:** отсутствие kudos-запроса проверяется
  ЧЕРЕЗ mitm-перехват сети за время выполнения When (тот же приём, что
  TC-227/TC-230 в области sync), а не через отсутствие UI-подтверждения —
  если бы гипотетический баг всё же нашёл «чужую» открытую вкладку и
  отправил kudos, тест обязан это увидеть по трафику.
- Требует поднятого mitm-прокси в режиме наблюдения — не обязательно
  server-replay для этого конкретного теста (позитивная work-страница не
  нужна вовсе, раз вкладок нет).
