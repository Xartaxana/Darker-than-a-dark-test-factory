# TC-219 — Snippet ID: адверсариальный ввод отфильтрован до цифр

## Предусловия
- Секция Sync открыта, поле Snippet ID пусто.

## Сценарий (Given-When-Then)

**Given** поле Snippet ID пусто

**When** пользователь пытается ввести буквы, пробелы и вставить (paste)
смешанную строку вида `"12a 3b45"`

**Then** в поле остаются ТОЛЬКО цифры введённой/вставленной строки (в
примере — `"12345"`), нецифровые символы не появляются в поле ни при вводе
по одному символу, ни при вставке целиком

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Вводимая строка (посимвольно) | `"1"`,`"2"`,`"a"`,`" "`,`"3"`,`"b"`,`"4"`,`"5"` |
| Вставляемая строка (paste) | `"12a 3b45"` |
| Ожидаемое содержимое поля | `"12345"` в обоих случаях |

## Заметки для автоматизации
- Адверсариальная мини-батарея по DoD (величина/кодировка/вставка) —
  дополнительно стоит попробовать пустую вставку и очень длинную цифровую
  строку (переполнение поля не специфицировано кодом — если проявится
  ограничение длины, это находка для отчёта, не повод менять Then).
- Блокера нет — стандартный Compose `TextField`-ввод, инструментарий уже
  используется другими settings-кейсами.
