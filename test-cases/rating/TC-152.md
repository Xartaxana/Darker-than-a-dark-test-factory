# TC-152 — Deselect через overlay листинга НЕ теряет downloadPath и личные теги скачанной работы (ожидаемо-красный, BUG-021 расширен)

## Предусловия
- Работа W (`ao3_id 900000001`) — тот же baseline A, что TC-151: скачанный
  файл (`downloadPath != null`), локальные `title="ЛОКАЛЬНЫЙ заголовок"`,
  `fandom="Мой фандом"`, `wordCount=777777`, рейтинг `SAVE`, заметка `"note A"`,
  личный тег `"tagA"`.
- Открыта листинговая страница, содержащая блёрб работы W; Rate-кнопкой
  открыт нативный overlay (`RatingOverlay`) — Favorite показан выбранным,
  overlay показывает «Already downloaded», превью заметки и `'Saved tags (1)'`.
- Режим replay (`listing_basic.mitm`); `auto_download_saved` выключен (сверено
  в prefs — не относится к BUG-014/015).

## Сценарий (Given-When-Then)

**Given** работа W скачана, имеет рейтинг Favorite, личную заметку `"note A"`
и личный тег `"tagA"`; на листинге overlay рейтинга раскрыт, Favorite показан
выбранным

**When** пользователь повторно нажимает уже выбранную кнопку Favorite в
overlay (deselect)

**Then** рейтинг снимается (`rating → null`), строка не удаляется (заметка
непуста)
**And** `downloadPath` остаётся НЕИЗМЕННЫМ — тем же путём на тот же файл на
диске (файл никуда не делся — связь строка↔файл не должна рваться операцией,
которая файла не касается)
**And** личный тег `"tagA"` остаётся среди сохранённых тегов работы
**And** `title`/`fandom`/`wordCount` остаются ЛОКАЛЬНЫМИ значениями (заметка —
операция над одним полем, не пересборка строки)
**And** карточка Library продолжает показывать иконку «Open downloaded»
(не переключается на Download)

**ОЖИДАЕМОЕ ПАДЕНИЕ на текущей сборке** (прецедент TC-048/TC-139: кейс
формулируется по ожидаемому поведению спецификации, факт красноты — здесь, не
в заголовке): по коду (`BrowserViewModel.kt:807-813`) `applyRating` при
`rating == null` конструирует НОВЫЙ `WorkRating(...)`, в списке аргументов
которого `downloadPath` ОТСУТСТВУЕТ (дефолт `null`) и `tags` берётся только из
полей overlay (`savedTags`, без учёта `existing.tags`) — реально
`downloadPath` обнулится, тег `"tagA"` исчезнет, `title/fandom/wordCount`
перезапишутся скрейпом страницы, карточка переключится на «Download». Then не
совпадёт с фактом. Красный результат триажится как **APP_BUG/BUG-021
(расширение, дверь 2)**, не как расхождение теста со спекой; ссылка:
`bugs/BUG-021.md`.
