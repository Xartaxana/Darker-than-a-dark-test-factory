# TC-251 — Тумблер громкости: дефолт и персистентность

## Предусловия
- Приложение запущено с чистыми данными (первый запуск, prefs пусты).

## Сценарий (Given-When-Then)

**Given** первый запуск приложения, Settings открыт

**When** пользователь смотрит на тумблер «Page with volume buttons», затем
выключает его и перезапускает приложение (kill+relaunch)

**Then** ДО первого действия тумблер уже показан ВКЛЮЧЁННЫМ (дефолт ON без
действий пользователя)
**And** после выключения и рестарта тумблер остаётся ВЫКЛЮЧЕННЫМ —
значение пережило рестарт

## Проверяемые данные
| Параметр | Значение |
|---|---|
| Дефолт (первый запуск) | ON |
| После выключения + рестарта | OFF (сохранено) |

## Заметки для автоматизации
- Блокера нет — обычный settings-toggle persistence паттерн, не требует
  нажатия клавиш громкости (в отличие от TC-252..255, заблокированных
  `bugs/AT-BUG-072.md`).
