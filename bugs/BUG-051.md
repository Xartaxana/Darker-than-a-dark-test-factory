# BUG-051 — Поиск в Library принимает чисто пробельный запрос

## Окружение
- Версия: 1.10 (versionCode 11), commit 63f6aac

## Шаги воспроизведения (Given-When-Then)

**Given** Library с ≥1 работой, поле поиска пустое
**When** пользователь вводит только пробелы
**Then (ожидание)** запрос игнорируется (trim), список не меняется
**Then (факт)** список мгновенно показывает пустую выдачу, затем возвращается — видимое мигание

## Частота
Всегда.

## Анализ
Отсутствие trim перед фильтрацией; косметика.
